## GitHub Pages
1. Créer un dépôt GitHub.
2. Déposer tous les fichiers à la racine du dépôt (y compris icons).
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Ouvrir l’adresse HTTPS publiée puis cliquer sur Installer.

Les données restent dans le navigateur. Exporter régulièrement une sauvegarde JSON. WhatsApp nécessite Internet. Les métrés sont estimatifs, pas une validation des systèmes constructifs. Renseigner les prix et la TVA applicables.
